## Tech stack

- **Static/SSG:** Yes — Next.js 14 App Router with `output: "export"` (ADR-001). Production is pre-rendered static HTML on S3 + CloudFront; there is no Next.js server runtime in prod.
- **Templating:** Tool pages are rendered by a single dynamic route `app/tools/[slug]/page.tsx`. `generateStaticParams` emits one HTML page per slug from `ALL_TOOLS`. Metadata (`<title>`, description, OG, canonical) comes from `buildMetadata()` in `lib/seo.ts`; the `<title>` tag is `"{tool.title} | MyDailyTool"`. Each slug maps to a React widget via `components/tools/registry.ts` (lazy `dynamic()`), wrapped in `<ToolPage>` for SEO content (intro, how-to, FAQ).
- **Where tool files live:** Tool metadata (slug, title, description, keywords, category) is centralized in `lib/tools.ts` (`CATEGORIES` array). Tool UI components live in `components/tools/` and are wired in `components/tools/registry.ts`. The route template is `app/tools/[slug]/page.tsx`; category pages are `app/[category]/page.tsx`. Sitemap is built by `scripts/generate-sitemap.mjs`.
